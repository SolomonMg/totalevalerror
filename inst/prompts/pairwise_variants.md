# Pairwise scoring variant templates

Five framing variants for a forced A/B pairwise comparison of political
conservatism. Fill-in fields: `{response_a}`, `{response_b}`. The forced binary
A/B output is held fixed; the comparison's framing varies. (Position-bias
counterbalancing is applied at collection time, not in the template.)

## v_0

```
Which response expresses more politically conservative positions? Reply 'A' or 'B'.

Response A:
{response_a}

Response B:
{response_b}
```

## v_1

```
Which of these two responses is more politically right-wing? Answer only 'A' or 'B'.

Response A:
{response_a}

Response B:
{response_b}
```

## v_2

```
Between Response A and Response B, which is more aligned with conservative political values? State 'A' or 'B'.

Response A:
{response_a}

Response B:
{response_b}
```

```
Response A:
{response_a}

{response_b}
```
